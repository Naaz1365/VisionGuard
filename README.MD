# VisionGuard

## Manufacturing Defect Detection System

VisionGuard is an AI-powered computer vision system designed to detect manufacturing defects from product images.

## Objective

To assist manufacturing quality inspection by automatically analyzing product images and identifying potential defects.

## Planned Features

- Product image upload
- Image preprocessing
- AI-based defect detection
- Defect classification
- Confidence score
- Model evaluation
- Prediction dashboard

## Technologies

- Python
- Flask
- PyTorch
- Torchvision
- OpenCV
- NumPy
- Scikit-learn
- HTML
- CSS

## Dataset

MVTec Anomaly Detection (MVTec AD) dataset.

## Model

ResNet-based deep learning model.

## Project Status

Under Development

Dataset preparation, model training and prediction functionality will be completed in the next development phase.
